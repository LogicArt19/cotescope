Chaque pronostic de la sélection Cotescope est inscrit ici avant le coup d'envoi, puis le résultat officiel est ajouté après le match. Rien n'est jamais effacé.

Comment vérifier ? Ce registre est un fichier du dépôt public GitHub de Cotescope : l'historique daté de GitHub montre quand chaque ligne a été ajoutée, et il ne peut pas être réécrit sans que ça se voie. Chaque ligne porte aussi une empreinte SHA-256 qui dépend de la ligne précédente : modifier un ancien pronostic casserait toute la chaîne. Ton navigateur la recalcule ci-dessous.
